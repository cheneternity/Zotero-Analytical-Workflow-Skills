# ResearchVault 知识库模板说明

本目录用于 `01knowledge` 中不同类型知识页的结构化写作。

## 模板类型

| 模板 | 适用对象 | 核心任务 |
|---|---|---|
| `主题模板.md` | 宏观研究主题 / 综合议题 | 汇总证据、形成阶段性综合判断 |
| `概念模板.md` | 概念、指标、变量 | 明确定义、边界、测量与混淆项 |
| `方法模板.md` | 模型、统计方法、空间分析方法 | 说明用途、假设、参数、诊断与误用 |
| `关系模板.md` | X→Y、X↔Y、机制链 | 组织方向、强度、非线性、异质性与因果证据 |
| `争议模板.md` | 文献结论冲突 / 理论争议 | 对照竞争观点并解释分歧来源 |

---

## 一、统一写作原则

### 1. 先写“判断”，再堆“文献”
知识页不是文献摘要集合。正文优先回答：

- 目前能确定什么？
- 证据在哪些条件下成立？
- 哪些内容还不能推广？
- 下一步缺什么证据？

### 2. 区分证据状态
建议统一使用：

- `fulltext_verified`：关键结论已由全文核验。
- `note_supported`：目前只由正式 Literature Note 支持，尚未全文定向核验。
- `mixed`：页面同时包含以上两类证据。
- `provisional`：临时综合判断，证据尚不足。

### 3. 区分证据角色
关系与主题页中建议标记：

- `direct`：研究直接检验该结论。
- `conditional`：结论依赖特定尺度、模型、情境或参数。
- `mechanistic`：主要支持机制链中的某一环。
- `contextual`：提供背景或外部有效性证据。
- `counter`：与当前主判断相反或构成限制。

### 4. 不跨越证据边界
以下情形不得自动写成一般规律：

- 单城市 → 跨城市规律
- 横截面相关 → 因果关系
- 情景模拟 → 现实政策效果
- 运行碳 + 隐含碳分别核算 → 完整生命周期因果关系
- 单一空间尺度 → 多尺度稳定结论
- 模型解释变量重要性 → 真实机制确认

### 5. 页面保持“两层阅读”
每页都应允许：

- **30 秒阅读**：顶部摘要卡 + 当前判断。
- **深入阅读**：证据矩阵、边界条件、来源与研究空白。

### 6. 知识准入与最小科研粒度

只创建可复用的科研知识单元：一个研究现象、概念、操作化、方法、方向性关系、机制、明确争议或研究设计模式。新节点必须至少能支持研究问题、假设、变量/指标选择、方法选择、实证解释、边界条件、跨研究比较或研究空白中的一项；否则保留在 Analytical Note。

不要把高频宽泛词直接做成最终节点。`城市形态`、`城市环境`、`城市热环境`、`城市碳排放`、`可持续城市`和`建成环境`可作为导航或父级标签，但应优先落到“因素—结果—条件”明确的研究单元。

### 7. 城市研究的默认检查框架

对城市研究页，检查研究对象、现象/结果、解释因素、机制、空间和时间尺度、城市/气候/制度情境、测量、方法、证据类型与边界条件。若结论仅在特定条件成立，应明确写为“情境依赖”，不得绝对化。

---

## 二、建议文件命名

保持短、稳定、可链接：

- 主题：`城市形态与建筑环境绩效`
- 概念：`建筑生命周期碳`
- 方法：`空间计量与空间异质性建模`
- 关系：`城市形态—碳排放`
- 争议：`紧凑度是否降低碳排放`

尽量避免把年份、作者名、单篇论文题名写入知识页文件名。

---

## 三、建议 Knowledge Page 的最低完成标准

一页只有在满足以下条件后才建议标记为稳定知识页：

1. 有明确的“当前判断”；
2. 结论与证据来源可追溯；
3. 至少说明一个边界条件；
4. 没有把相关性写成因果性；
5. `fulltext_verified` 与 `note_supported` 状态没有混淆；
6. 研究空白来自证据缺口，而非泛泛而谈；
7. 能与其他概念 / 方法 / 关系页形成双向链接。
8. 对关系、争议和综合页，来源可由 `source_notes` 追溯到正式 Analytical Note 与 `zotero_key`。
9. 不将预测、模型解释或单城市相关表述为因果或普适规律。
